# Proyecto Final — Pentesting y Hardening Debian WordPress

Proyecto de análisis forense, explotación controlada, hardening y mitigación
sobre un servidor Debian con Apache2, MariaDB y WordPress.

## Contenido

- Informe técnico completo PDF
- Evidencias forenses
- Mitigaciones aplicadas
- Validaciones técnicas
- Capturas de pantalla
- Script automatizado de hardening

## Tecnologías utilizadas

- Debian Linux
- Apache2
- MariaDB
- WordPress
- SSH
- Bash scripting

## Frameworks y estándares aplicados

- ISO 27001
- NIST SP 800-61
